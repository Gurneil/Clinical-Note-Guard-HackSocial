Against the obvious approach

The baseline is the naive version of this product: one prompt, transcript plus note, "point out any errors." Both systems ran on the same 51 planted errors and the same 6 clean controls.

Does each node earn its place?

Every flag records which node raised it, so the same run can be re-scored with any node withheld — no re-run, no extra API spend. This is the pipeline marking its own homework in public.

Node 3 · entailment +45.1 pts 23 errors nothing else caught. Also 11 of the 15 false positives — the literalism cuts both ways.
Node 5 · omission +3.9 pts 2 errors nothing else caught, for 4 false positives. One of them wasn't even an omission — it was a medication attributed to the wrong person.
Node 4 · numeric regex +0.0 pts Caught nothing the entailment node hadn't already caught. It stays because it costs no model call and raised zero false positives — but on this benchmark it is not adding coverage, and saying otherwise would be a nicer story than the data supports.

What counts as an error

Six categories

Stated plainly

What this doesn't do

A QA tool that oversells itself is a patient-safety problem. So here is the other side of the table.

No clinical judgment

It doesn't diagnose, doesn't recommend treatment, and doesn't decide whether a note is correct. It decides whether the note matches the transcript, and hands that to a person.

Decomposition costs precision

Seven atomic claims mean seven chances for a false alarm instead of one. On a clean note the pipeline raised 7 flags where the baseline raised 2. That is a real trade, not a rounding error.

The exact checker is narrow

Node 4 recognises mg/mcg doses and blood-pressure pairs. Units outside that set fall back to the LLM entailment check, with the ambiguity that implies.

The scoring here is a proxy

Reported numbers come from the automated scorer. A blinded human grading pass on the same committed outputs is the next step, and the blind scorecard is in the repo so anyone can run it.

Synthetic data only

Sixty invented transcripts about fictional patients, written for this project. No real patient data is used, needed, or stored anywhere.

Sample size is small

Sixty cases is enough to compare two systems on the same benchmark. It isn't enough to publish a clinical claim, and this project doesn't make one.
